# ADR-0002 предоставление доступа к ставкам из колл-центра и из внешнего колл-центра

### **Автор:** Иванов А А

### **Дата:** 2026-02-27

## **Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case**                                     | **Описание** |
| :---: | :------------------------------- | :----------------------------------------------- | :----------- |
|   1   | Сотрудник колл центра            | получает информацию по текущим ставкам депозитов |              |
|   2   | Сотрудник внешнего колл центра   | получает информацию по текущим ставкам депозитов |              |
|   3   | Сотрудник банка                  | загружает новые ставки по депозитам в АБС        |              |

## **Нефункциональные требования**

| **№** | **Требование**   | описание                                                          |
| :---: | :--------------- | ----------------------------------------------------------------- |
|   1   | доступность      | ставки должны быть доступны все время                             |
|   2   | актуальность     | все ставки должны быть одинаковыми и на сайте и в колл центре     |
|   3   | безопасность     | для передачи должны использоваться только безопасные каналы связи |
|   4   | поддерживаемость | разработкой должна заниматься текущая команда разработки          |

## **Решение**

### Описание

В сервисе интернета-банка реализовать API для получения ставок по депозитам. Сотрудники колл-центра и внешнего колл-центра будут обращаться к этому API для получения актуальной информации о ставках. Сотрудник банка будет загружать новые ставки в АБС, и эти ставки будут автоматически обновляться в сервисе интернет-банка.
