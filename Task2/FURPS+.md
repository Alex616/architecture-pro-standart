# FURPS+

| Код  | Требования                                                                                                                        | Комментарий                                                                   |
| ---- | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| F    | Функциональные (Functionality)                                                                                                    |                                                                               |
| F1   | На сайте новый клиент видит список доступных депозитов с актуальными ставками.                                                    |                                                                               |
| F2   | Клиент может подать заявку на депозит, оставив свой номер телефона и Ф. И. О.                                                     |                                                                               |
| F3   | Интернет-банком может пользоваться только зарегистрированный пользователь                                                         | Так как у нас есть персонализация нам нужна регистрация                       |
| F4   | Персонализированные ставки депозитов лично для пользователя                                                                       |                                                                               |
| F5   | Открывать депозит через сайт указав счет и сумму депозита                                                                         |                                                                               |
| F6   | Заявку на открытие депозита обрабатывает менеджер бек-офиса                                                                       |                                                                               |
| F7   | На сайте новый клиент видит предложение открыть кредит по некоторой ставке                                                        |                                                                               |
| F8   | Клиент может подать заявку, оставив свой номер телефона и Ф. И. О.                                                                |                                                                               |
| F9   | Если клиент заполнит паспортные данные, то предполагается сразу выдать ему решение об (не)одобрении ему кредита.                  |                                                                               |
| F10  | Если клиент пришел в отделение банка, то менеджер должен продолжить работать с той же заявкой что ранее составил клиент на сайте. |                                                                               |
| F11  | Менеджер в отделении создает заявки на кредит для клентов через АБС.                                                              |                                                                               |
| F12  | В интернет - банке клиент видит предодобренное предложение по кредиту                                                             | по нему произошел скоринг и была рассчитана приемлемая сумма кредита          |
| F13  | Предодобреные завки обрабатываются быстрее, так как считать по ним полный скоринг не нужно                                        |                                                                               |
|      | ...                                                                                                                               |                                                                               |
| U    | Удобство использования (Usability)                                                                                                |                                                                               |
| U1   | Клиент получает СМС-код для открытия депозита и подачи заявки на кредит                                                           |                                                                               |
| U2   | Сотрудники бек-офиса кредитов и депозитов должны иметь возможность работать со ставками по депозитам (в АБС)                      |                                                                               |
| U3   | Клиент получает СМС-уведомление после подтверждения размера ставки и открытия депозита.                                           |                                                                               |
| U4   | Есть система дизайна принятая внутри компании, нужно ее придерживаться                                                            |                                                                               |
| U5   | После подачи заявки клиенту приходит СМС о том, что нужно прийти в отделение для получения кредита и идентификации.               |                                                                               |
| U6   | СМС-оповещения об изменении статуса кредита                                                                                       |                                                                               |
|      | ...                                                                                                                               |                                                                               |
| R    | Надёжность (Reliability)                                                                                                          |                                                                               |
| R1   | RPO - 10 минут                                                                                                                    |                                                                               |
| R2   | RTO - 30 минут                                                                                                                    |                                                                               |
| R3   | SLA - 99,9                                                                                                                        |                                                                               |
| R4   | SLO - 99,99                                                                                                                       |                                                                               |
|      | ...                                                                                                                               |                                                                               |
| P    | Производительность (Performance)                                                                                                  |                                                                               |
| P1   | Загрузка страницы максимальна быстрая (не более 1 секунды)                                                                        |                                                                               |
| P2   | Горизонтальное масштабирование АБС                                                                                                |                                                                               |
| P3   | Предодобреные заявки на кредит должны обрабатываться в тот же день                                                                |                                                                               |
|      | ...                                                                                                                               |                                                                               |
| S    | Поддерживаемость (Supportability)                                                                                                 |                                                                               |
| S1   | Разработать документацию                                                                                                          |                                                                               |
| S2   | Обеспечить совместимость старых технологий банка c новыми технологиями используемых при построении новой системы                  |                                                                               |
|      | ...                                                                                                                               |                                                                               |
| +R   | + Ограничения (Restrictions)                                                                                                      |                                                                               |
| +R1  | Передаваемые пользовательские данные необходимо защищать с помощью алгоритма шифрования - TLS 1.2+                                |                                                                               |
| +R2  | Реализовать СМС-оповещения (код) в обход АБС                                                                                      |                                                                               |
| +R3  | Данные передаваемые внутри банка также надо защищать алгоритмом шифрования - TLS 1.2+                                             |                                                                               |
| +R4  | БД MSSQL и Oracle, возможно PostgreSQL                                                                                            | PostgreSQL - так как в компании есть люди писавшие скоринг                    |
| +R5  | Использовать Kafka                                                                                                                |                                                                               |
| +R6  | Сделать открытие депозитов через микросервисную архитектуру                                                                       |                                                                               |
| +R7  | АБС может масштабироваться только вертикально из-за своей бд (прямую работу с интернет-банком может не пережить)                  |                                                                               |
| +R8  | Обмен данными между бд АБС и кредитным конвейром ускорить нельзя (раз в сутки)                                                    |                                                                               |
| +R9  | Кредитный-конвейр и система кредитного скоринга поддерживают горизонтальное масштабирование                                       |                                                                               |
| +R10 | На систему кредитного скоринга не должно приходиться больше 100 RPS                                                               |                                                                               |
| +R11 | Язык разработки .Net, Java и Python                                                                                               | .Net - Интернет-банк; Java - компоненты Кредитного-конвейра; Python - скоринг |
| +R12 | RPS на создание заявок по депозитам/кредитам - ожидается в пределах от 500 до 1000 RPS                                            |                                                                               |
